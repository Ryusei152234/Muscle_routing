# Muscle Routing
筋トレが続かない人のための記録・継続支援アプリです。  
トレーニング内容を記録・共有できるSNS風のWebサービスとして、ユーザー同士の投稿閲覧や記録の可視化を通じて、モチベーション維持をサポートすることを目的に開発しました。

## 開発背景
筋トレや運動習慣は、目標設定だけでは継続が難しく、記録の習慣化や他者との共有によるモチベーション維持が重要だと考えました。  
そこで、日々のトレーニングを投稿として残し、継続状況を振り返れるWebアプリケーションを開発しました。

## 使用技術
- Ruby
- Ruby on Rails
- HTML / CSS
- JavaScript
- Render
- GitHub

## 主な機能
- ユーザー登録・ログイン機能
- トレーニング投稿機能
- 投稿一覧表示
- 投稿詳細表示
- 投稿編集・削除機能
- SNS風の記録共有機能

## 工夫した点
- 初心者でも直感的に使えるシンプルなUI設計
- トレーニング記録を継続しやすい投稿導線
- SNS風に共有できることで、モチベーション維持につながる設計
- Renderを用いた本番環境へのデプロイ
